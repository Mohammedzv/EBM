IBM System — نسخة المزامنة بين الأجهزة

هذه النسخة تستخدم Firebase Realtime Database لمزامنة الماكينات وسجلات الصيانة عبر الأجهزة. يجب تشغيلها من رابط HTTPS مثل GitHub Pages، وليس بفتح index.html مباشرة من مدير الملفات.

خطوات التشغيل:
1) ارفع index.html إلى GitHub Pages (أو استبدل ملف الموقع الحالي به).
2) افتح Firebase Console للمشروع sstmy-627dc.
3) افتح Build > Realtime Database > Rules.
4) لأغراض الاختبار فقط، أضف قواعد ibmSystem الموجودة في database.rules.json ثم اضغط Publish.
5) افتح الموقع من رابط GitHub Pages على الجهاز الأول، أضف ماكينة، ثم افتح نفس الرابط على جهاز ثانٍ مع الإنترنت. يجب أن تظهر البيانات على الجهازين.

تنبيه أمني مهم: القواعد الاختبارية تسمح لأي شخص يعرف رابط قاعدة البيانات بقراءة وتعديل بيانات IBM System. لا تستخدمها لبيانات حساسة أو على موقع عام دائم. قبل الاستخدام الفعلي ينبغي إضافة تسجيل دخول وصلاحيات Firebase Authentication وقواعد آمنة.

ملحوظة: بيانات النسخة المحلية القديمة لن تنتقل تلقائيًا إلى السحابة؛ هذه النسخة تبدأ بمسار سحابي منفصل ibmSystem/state.
