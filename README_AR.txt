IBM System — نسخة الإشعارات الصوتية

1) فك الضغط وارفع مجلد IBM_System إلى GitHub Pages مع استبدال الملفات القديمة.
2) افتح الموقع عبر HTTPS. اضغط زر «تفعيل الإشعارات والصوت» واسمح بإشعارات المتصفح.
3) عند وصول بلاغ توقف جديد من جهاز آخر، سيظهر تنبيه داخل الموقع وإشعار المتصفح ويصدر صوت تنبيه، بشرط أن الصفحة مفتوحة وأن المتصفح يسمح بالصوت والإشعارات.
4) جرّب إرسال بلاغ من جهاز ثانٍ.

مهم: المتصفح قد يمنع الصوت قبل أول ضغطة من المستخدم، لذلك اضغط زر التفعيل مرة واحدة. الإشعارات والصوت لا يضمنان العمل إذا كان الموقع مغلقًا تمامًا أو الهاتف يقيّد عمل المتصفح بالخلفية.

تنبيه أمان: قواعد Firebase المفتوحة للاختبار فقط وليست آمنة للاستخدام الفعلي. أضف تسجيل دخول وقواعد أمان قبل تخزين بيانات حقيقية.
