IBM System — نظام صيانة الماكينات

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح، أو ارفع الملف إلى GitHub Pages.
3) أضف ماكينة واكتب رقم الماكينة ونوعها ثم اضغط «حفظ الماكينة».
4) ستظهر رسالة نجاح وستظهر الماكينة في القائمة ولوحة التحكم.
5) سجلات الصيانة تحفظ بالطريقة نفسها.
6) استخدم زر «نسخة احتياطية» لتنزيل ملف JSON يحتوي على البيانات.

مهم:
- هذه النسخة تحفظ البيانات في مساحة التخزين المحلية للمتصفح (localStorage)، ولا تحتاج Firebase أو قاعدة بيانات أو تسجيل دخول.
- البيانات تبقى على نفس الجهاز والمتصفح. مسح بيانات المتصفح أو فتح الموقع على جهاز آخر لا ينقل البيانات؛ نزّل نسخة احتياطية بشكل دوري.
- لا تستخدم زر مسح بيانات الموقع إذا كنت تريد الاحتفاظ بالسجلات.
